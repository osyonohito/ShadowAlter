# Re-Shadowverse
 
Re-Shadowverse は、サービス終了した旧作「Shadowverse」をもう一度遊べるようにすることを目的とした、非公式の個人開発プロジェクトです。
 
既存の公式クライアント（Steam版・DMM版）を活用し、独自のサーバー環境を通じて、かつてのゲーム体験を再現することを目指しています。
 
## プロジェクトについて
みなさんは Shadowverse という作品を知っているでしょうか？
 
リリースから10年。（良くも悪くも）誰しもが忘れられないデッキやカードがあるでしょう。
 
ニュートラルヴァンパイアに親を殺された人、エイラビショップに木っ端みじんに吹き飛ばされた人
ゴキブリに五体不満足にされた人、超越に延々とソリティアを見せつけられた人
ベイリオンに無限に殴り続けられた人、バハムートにすべてをひっくりかえされた人
ヘクターに轢き殺された人、AFと犬に決められた人
 
いろんな怨嗟の声が残る中、それでもランクマやグランプリ、RAGEなどの大会に挑んだ猛者たち
どうしようもないカードを愛し、フリマで活躍させようと頑張る猛者たち
 
理不尽な展開にキレ、民度の低いキッズには煽られ、魔境アンリミに震え続けた
クソゲークソゲーと揶揄しながらも、それでも遊び続けた10年間
Beyond も発売されて、少しずつそっちにシフトして…
 
…ほんとうに心残りはないですか？
 
レッドエーテルがなくて諦めたデッキ
加速開放をフルで積んだ机上論上 Tier God のAFネメシス
全てのカードが使えるクロスオーバー
リサージェントカードと昔のカードの組み合わせ
 
ただの再現だけじゃない、あの時夢見た構成を再現したくないですか？
それを叶えるために、開発しました
 
なお、本プロジェクトは現在進行形で様々なバグと格闘中です
まだまだ開発途中なので、不具合を見つけた方は一報ください。
 
 
## 特徴
 
- 旧Shadowverseのゲーム環境を再現
- オンライン対戦（フリーマッチ、ルームマッチ）に対応
- マイローテーション / アンリミテッド / クロスオーバー に対応
- 基本的なゲーム機能をできる限り当時の状態で維持
- 完全無料
## インストール
 
配布されたZIPファイルを任意の場所に展開してください。
 
例：
 
```text
C:\Re-Shadowverse\
```
 
展開後、Re-Shadowverse.exe を起動してください。
 
初回起動時に必要な設定やゲームファイルの確認が行われます。
 
※ 起動には正規に入手したSteam版・DMM版のゲームファイルが必要です
 
※ Program Files など、書き込みに管理者権限が必要なフォルダには置かないでください（自動更新ができなくなることがあります）
 
## 起動方法
 
1. Re-Shadowverse.exe を起動
2. 必要な処理が完了するまで待つ
3. Shadowverseが起動
4. 通常通りゲームをプレイ
Re-Shadowverse経由で起動している間だけ、コミュニティサーバーへの接続に必要な処理が適用されます。
 
ゲーム終了後は、Re-Shadowverseによる一時的な変更も終了します。
 
Steam版・DMM版のインストールファイルそのものを恒久的に書き換えることはありません。
 
## アップデート
 
バージョン 1.0.0 以降、Re-Shadowverse.exe は起動時に自動で最新版へ更新されます。
 
更新は次回の起動から反映されます。手動で配布ファイルを入れ替える必要はありません。
 
## 言語設定
 
`config.json` の `language` で使用言語を変更できます。
 
日本語：
 
```json
{
  "language": "ja"
}
```
 
英語：
 
```json
{
  "language": "en"
}
```
 
現在正式に対応している言語は以下です。
 
- 日本語
- English
英語はSteam版のみ対応しています。DMM版は日本語のみです。
 
英語に設定した場合、カード名や能力などの文章は英語になりますが、文字入りの画像やストーリーなど一部は日本語のまま表示されます。
 
他の言語への対応は保証しておりません。
 
## 対応フォーマット
 
現在は以下の3形式を基本フォーマットとして使用します。
 
- マイローテーション
- アンリミテッド
- クロスオーバー
タイムスリップローテーションは本作の意図とそぐわないと判断したため、通常のデッキ形式としては使用しません。
 
## 対戦について
 
Re-Shadowverseのオンライン機能は、公式Shadowverseのサーバーではなく、Re-Shadowverse用のコミュニティサーバーを使用します。
 
プレイヤー数が少ない時間帯は、対戦相手が見つかりにくい場合があります。
 
開発途中のため、一部のカードや特殊な処理で正常に対戦を完了できない可能性があります。
特に非公開情報（手札や山札）に関係する能力によるものが多いです（例：デッドソウルテイカー）
 
ゲーム内の設定「通信を暗号化する」はオフのままにしてください。オンにすると対戦に接続できません。
 
### リサージェントカード
 
リサージェントカードは、通常のカードと同様にデッキに入れることができます。
（ただし、フリーマッチでは使用できません。）
 
昔のカードと新しいカードを組み合わせて遊べるよう、以下のカードは一部のカード効果でお互いを同じカードとして扱うように変更しています。
 
- 「ナテラの大樹」と「ナテラの宝樹」
- 「ラピッドファイア」と「信念の加速」
- 「リペアモード」と「リカバリー」
数える・選ぶ・除外するといった効果で両方が対象になります。それぞれのカード名や効果そのものは変わりません。
 
### 不具合の報告
 
不具合を見つけた場合は、可能であれば以下の情報を添えて報告してください。
 
- 試合をした時間（だいたいでOK。例：11/15 23:40ごろ）
- 試合の種類（ルームマッチ／フリーマッチ／CPU戦、ルームならルーム番号）
- 対戦した2人（誰と誰か）
- 何ターン目ごろか
- おかしかった場面で使ったカード（そのターンと直前のターンのもの）
- 発生した現象（何が起きて、本当はどうなるはずだったか）
- 自分の画面と相手の画面で何が違ったか（分かれば）
- スクリーンショット（あれば）
公開の場で報告する際は、パスワードや認証情報などは含めないでください。
 
## 寄付について
 
Re-Shadowverseは完全無料です。
 
寄付をしなくても、機能・アップデート・オンライン対戦などに違いはありません。
 
寄付者限定機能、ゲーム内特典、優先接続などもありません。
 
サーバーやその他のインフラ維持には費用がかかるため、運営を支援したい方からの任意の寄付を受け付ける場合があります。
 
寄付はあくまで任意です。
 
十分な運営資金が確保できた場合、寄付の受付を一時停止することがあります。
 
## 大切なこと
 
Re-Shadowverseは非公式のファンプロジェクトです。
 
株式会社CygamesおよびShadowverse公式とは関係ありません。
 
Shadowverseに関連する名称・画像・音声・その他の著作物の権利は、それぞれの権利者に帰属します。
 
Re-Shadowverseは、旧Shadowverseを好きだった人たちが、サービス終了後もゲームを楽しめる環境を残すことを目的として開発されています。

といった問題が発生する可能性があります。
 
重要なデータについては各自でバックアップを行ってください。
 
本プロジェクトは現状のまま提供され、継続的な稼働や不具合がないことを保証するものではありません。
