# ShadowAlter

[English](README.md) | [日本語](README-ja.md)

## ダウンロード

[Download ShadowAlter](https://github.com/osyonohito/ShadowAlter/releases/latest)

ShadowAlterは、サービス終了した旧作「Shadowverse」を再び遊べるようにするための、非公式の個人開発プロジェクトです。

既存のSteam版・DMM版クライアントと独自のサーバーを使用し、ゲーム環境の再現を試みています。

現在も開発途中のため、正常に動作しない機能やカードがあります。

## 現在できること

- CPU対戦
- オンライン対戦（フリーマッチ・ルームマッチ）
- マイローテーション・アンリミテッド・クロスオーバー
- 日本語・英語への対応（英語はSteam版のみ）
- リサージェントカードの使用（一部対戦形式を除く）

一部のカード能力や特殊な処理では、対戦中に不具合が発生する場合があります。

## インストール・起動

1. [Releases](https://github.com/osyonohito/ShadowAlter/releases) から最新版のZIPをダウンロード
2. 任意のフォルダに展開
3. `ShadowAlter.exe` を起動

初回起動時はゲームデータの準備が行われます。

正規に入手した旧ShadowverseのSteam版またはDMM版のゲームファイルが必要です。

**注意事項**
- `Program Files` など、書き込みに管理者権限が必要な場所には展開しないでください。
- ゲームは必ず`ShadowAlter.exe`から起動してください。
- ゲーム内の「通信を暗号化する」はオフにしてください。
- リサージェントカード入りのデッキはフリーマッチでは使用できません。

## 不具合・お問い合わせ

不具合を発見した場合は、発生した状況、使用したカード、試合日時などを添えてご連絡ください。

改善案や要望なども歓迎しています。ただし、個人開発のため、すべてに対応できるとは限りません。

連絡先：shadowalter.dev@gmail.com
